`npm test` executa bootstrap/unidades. `npm run test:integration` exige `TEST_DATABASE_URL` explícita de loopback/garimpo_test e cria schema novo, preservado por execução. `npm run verify` inclui ambos. Nenhum fallback para dev, reset/drop/truncate de dados de usuário, fixture comercial ou serviço real. Para comandos de banco: exportar PATH conforme bootstrap e `source "$HOME/.local/share/garimpo/postgres17/environment.sh"`; `npm run db:migrate` aplica migrations à base dev explicitamente configurada, `npm run db:generate` gera cliente. Não executar migrate reset.

Consumidor `processNext` aceita somente efeitos transacionais no próprio banco. Usa `FOR UPDATE SKIP LOCKED`, savepoint para manter tentativa após falha e deduplicação do destino. Não executar HTTP/e-mail dentro do callback; integração externa e seus protocolos são incrementos posteriores. Idempotência exige ator/escopo derivado da autenticação futura, nunca de payload público; mantém hash canônico, referência e efeito em uma transação SERIALIZABLE com até três tentativas totais. Não há retenção/expiração inventada para chaves. Datas timestamptz/UTC; não há cálculo financeiro nesta tarefa.
